LikeTheWind 1.3 - Linux
=======================

1. Put your MAME pdrift.zip (World, Rev A) in the roms folder.

2. Make the AppImage executable:

   chmod +x LikeTheWind.AppImage

3. Run it:

   ./LikeTheWind.AppImage

The AppImage includes SDL2, ALSA and PulseAudio runtimes. Game data such as
settings and the prepared ROM cache stays in this folder beside the AppImage.

Controls
  Arrow keys / WASD  steer
  Up / W             accelerate
  Down / S           brake
  Space              gear
  1 / Return         start
  5 / C              coin
  Tab                settings menu
  Esc                quit
