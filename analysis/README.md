# Recompilation entry seeds

These files contain only 68000 code addresses derived from the user's ROM (plus
the fixed vectors/call targets). They contain no game data. The build uses them
to seed the native translator so the shipped build does not fall back to the
interpreter for routine entry points.

- `entries_*.txt` — direct-analysis entries, regenerated by `tools\analyse.py`.
- `extra_entries_*.txt` — coverage-guided entries collected from fallback
  reports with `tools\seed_from_coverage.py`.

`tools\build.ps1 -EntriesOnly` copies these into `work\analysis` before
translating. `-Package` enables entry seeding automatically so release builds
include the full native routine set.
